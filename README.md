# GET HIRED | Module 01 — Foundations v3

[فتح العرض التفاعلي](https://boodybo.github.io/get-hired-module-01-foundations/)

العرض التفاعلي موسع بموضوعات AI وأشكاله وTokens وInput/Output Tokens وContext Window والضوابط الأساسية، **دون الخروج عن المدة الرسمية البالغة 90 دقيقة**.

- العرض: `docs/index.html`
- الصورة: `docs/human_ai_review.png`، احفظها في نفس مجلد HTML
- ورقة الطالب المحدثة: `Student_Activity_Sheet.md`
- ملاحظات المدرّب: `Trainer_Implementation_Notes.md`
- شرح المصطلحات على شرائح عربية مع الاحتفاظ بالمصطلحات التقنية بالإنجليزية.
- التقسيم النصي للـTokens والنسب المرئية في Context Window أمثلة توضيحية فقط؛ لا تُقدَّم بوصفها قياسات حقيقية.
- الموقع الرسمي لأدوات AI يحتاج إنترنت؛ ملف العرض يعمل محليًا.

**التحكم:** Space / السهم لليسار للكشف أو التقدم؛ R إعادة؛ N ملاحظات؛ O فهرس؛ F ملء الشاشة.

**تحقق قبل العرض:** حجم الخط على جهاز العرض، اتجاه الرسم من اليمين إلى اليسار، توافر حسابات الأدوات، والاتصال.
